
set up a tooltip registry

each tooltip should be able to receive some sort of context that tells it what we are trying to render

for example
"ascension:item_name"

would be a tooltip that uses the item provided and returns it's name in the context


potentially change this to be a type

so we can define a tooltip_contents as such
source -> determines WHAT text is used
styles -> a list of custom style types that are applied TO the text

style_registry
    ->rare,common etc

ascension:rare_physique

"source":"ascension:physique_name",
"style":[
    }
         "type":"zenith:rgba"
         "r":255,
         "g":255,
         "b":255,
         "a":255
    }
]
